# Changelog

All notable Cursor FX releases will be documented here.

## English

### 0.9.18 – Build Icon Fix

- Correct the PyInstaller build script to embed the VINT application icon.
- Bundle the application assets required by the build.
- This is the current development baseline; it is not yet a published auto-update package.

### Upcoming

- Add a secure update checker.
- Verify downloaded package SHA-256 before installation.
- Preserve user-installed effect libraries and application settings.
- Add rollback/recovery behavior for failed updates.

## Tiếng Việt

### 0.9.18 – Sửa lỗi biểu tượng khi biên dịch

- Sửa tập lệnh biên dịch PyInstaller để nhúng biểu tượng ứng dụng VINT.
- Đóng gói các tài nguyên cần thiết của ứng dụng trong quá trình biên dịch.
- Đây là phiên bản nền hiện tại dùng cho phát triển; chưa phải gói cập nhật tự động đã được phát hành.

### Dự kiến trong các phiên bản tiếp theo

- Bổ sung chức năng kiểm tra cập nhật an toàn.
- Xác minh mã SHA-256 của gói tải xuống trước khi cài đặt.
- Giữ nguyên thư viện hiệu ứng do người dùng cài đặt và các thiết lập ứng dụng.
- Bổ sung khả năng quay lui/khôi phục nếu quá trình cập nhật thất bại.
